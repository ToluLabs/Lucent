Lucent locally hosted fonts

Original, unmodified Google Fonts WOFF2 subsets for Manrope v23 and IBM Plex Mono v20.
Weights and Unicode ranges match the upstream CSS. The family names are unchanged.
Both families are distributed under SIL Open Font License 1.1; copyright and license notices are preserved alongside these files.

Source CSS:
https://fonts.googleapis.com/css2?family=Manrope:wght@400..800&family=IBM+Plex+Mono:wght@400;500&display=swap

File provenance and SHA-256 digests are recorded in sources.json.
Change versioned font paths when upgrading assets; /fonts/ is cached as immutable.
